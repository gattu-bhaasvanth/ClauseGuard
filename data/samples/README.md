# Sample Real Estate Transaction Documents

This directory contains synthetic or public/anonymized sample documents representing realistic property transactions:
- `brochures/` - Developer marketing flyers and project specification brochures.
- `allotment_letters/` - Developer allotment letters confirming unit reservation and agreed pricing.
- `agreements/` - Builder-Buyer Agreements (BBA) and Agreements for Sale.
- `payment_schedules/` - Milestone-linked or time-linked payment schedules.
- `possession_letters/` - Possession hand-over notices and terms.

> **Privacy Notice**: Only strictly synthetic or anonymized documents with redacted personal identities should ever be placed here.
